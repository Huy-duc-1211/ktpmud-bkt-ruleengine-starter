# Tài liệu M1 của Hải

Tôi để phần bàn giao hiện tại trong [M1](M1/README.md), gồm thiết kế logic, kế hoạch test, CSV test case và các ghi chú review.

[M2](M2/README.md) chứa kế hoạch cho giai đoạn sau: test trạng thái nội bộ, integration, fixture và benchmark. Các phần này chưa được triển khai.

Test case giữ mã gốc `RULE-001`, `INV-005`, `TA15-...`, `D13-...`. Lần chỉnh cách viết này giữ nguyên input, expected và rule_id.

Bản bàn giao nằm trên nhánh `docs/m1-tests-hai`. Chỉ commit/push lên nhánh, không tạo PR hoặc merge.
